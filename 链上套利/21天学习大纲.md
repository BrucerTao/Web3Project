## 总原则（贯穿 21 天）

1. **一切产出证据化**：每个观察都进证据库（时间/链/资产/规模/路径/成本/结果/失败原因），没有记录的"感觉"不算数。
2. **只算净收益**：屏幕上的价差 ≠ 可执行的利润。任何机会先过成本清单（Gas、协议费、桥费、滑点、延迟、失败交易、资金占用）。
3. **小步验证**：历史数据 → 模拟 → Paper Trading → （可选）极小规模真实执行，逐级升级，随时可退。
4. **安全红线**：私钥/助记词永远不进任何 Agent、脚本、网站；不点陌生合约授权；只用官方 LI.FI 域名（li.fi / docs.li.fi）；真实执行金额 = 可全损金额。

**每日时间投入**：工作日 1.5–2h，周末 3h。每天必须有一个可检查的交付物，哪怕很小。

## 第一周（D1-D7，08-05 ~ 08-11）：建立套利地图——从"价差"到"净收益"

### Day 1（08-05 · 补课）｜链上套利机会全景
- 目标：建立机会结构分类框架，知道钱从哪里来、被谁赚走。
- 动作：读共学开篇与 Bruce 的分享；梳理七类机会：DEX 内（同池偏离/再平衡）、DEX 间（同链跨所）、三角套利、跨链套利、稳定币脱锚、清算、MEV（三明治/尾随/抢跑）。
- ✅ 交付：《套利机会分类地图》一页：每类的原理 / 所需能力 / 典型 Edge 大小 / 主要风险 / 竞争烈度，并回答：**哪些是个人可做的，哪些已被专业机构垄断？**

### Day 2（08-06 · 补课）｜AMM 机制与价格形成
- 目标：理解价格是怎么被"算"出来的，为什么会出现价差。
- 动作：学 x*y=k、流动性深度、价格冲击、滑点；对比 Uniswap v2 / v3（集中流动性）/ Curve（stableswap）；理解区块确认与最终性对执行窗口的影响。
- ✅ 交付：手算练习 1 题（给定池子储备和交易规模，算出成交均价与价格冲击）+ 笔记《池子储备如何决定价格》。

### Day 3（08-07 · 补课）｜"屏幕价差"与"可执行净收益"的差距
- 目标：把成本意识变成肌肉记忆。
- 动作：列全成本项：Gas、swap 费、桥费、滑点/价格冲击、延迟、失败交易、资金占用、被 MEV 截胡；找一个公开的"价差很大但实际亏钱"案例。
- ✅ 交付：《净收益核算清单 v1》（之后每个机会都用它过滤）。

### Day 4（08-08 · 今天）｜LI.FI 初体验：跨链聚合器是什么
- 目标：理解 LI.FI 的定位——"聚合器的聚合器"，报价即路由。
- 动作：用官网 widget 查真实报价：不同链（Ethereum/Arbitrum/Base 等）× 不同资产（USDC/ETH）× 不同规模（$100/$1k/$10k），至少 5 组；**加入 LI.FI Builders 社群（Discord），自我介绍并提一个问题**。
- ✅ 交付：《首批报价观察记录》表格：路径 / 所用桥 / 预计耗时 / 费用 / 预计到账。

### Day 5（08-09）｜读 LI.FI 文档，看懂一条路由
- 目标：从"会用"到"看懂"报价结构。
- 动作：精读 docs.li.fi（Quote API / routes / steps）；用 curl 调一次 /quote，读返回 JSON；理解 Diamond（facets）架构的设计意图（了解即可）。
- ✅ 交付：《路由拆解图》1 份：拿一条真实报价，画出 起始链哪个 DEX → 哪座桥 → 目标链哪个 DEX，标出每一段的费用与风险点。

### Day 6（08-10）｜变量观察：规模、时间、路径如何改变机会
- 目标：建立"多大规模的机会才值得做"的直觉。
- 动作：同一路由 3 种规模 × 2-3 个时段重复查询，记录报价变化；特别留意**路由何时切换**（桥拥堵/深度变化时聚合器换路）。
- ✅ 交付：小报告《规模 × 时段 vs 净到账》：数据表 + 3 条结论。

### Day 7（08-11）｜周复盘 #1
- 动作：整理本周全部笔记；回补分类地图；归档所有记录进证据库。
- ✅ 交付：周复盘：3 个最大收获 / 3 个未解问题 / 下周重点。
- 🚦 关卡：若还说不清"为什么 0.5% 的价差不一定是机会"，补课一天再进入下周。

**本周里程碑**：有一张自己画的套利地图 + 一份净收益清单 + 5 组以上真实 LI.FI 报价记录。

## 第二周（D8-D14，08-12 ~ 08-18）：LI.FI 深入 + Hermes 工作流 + 证据与信号系统

### Day 8（08-12）｜搭好 Hermes Agent，立下安全边界
- 目标：按 Bruce 的建议——先本地跑通，之后部署服务器 + Telegram 才有意义。
- 动作：安装并配置 Hermes；配置时明确安全边界：只读 RPC、只接公开 API，**私钥永不入 Agent**；跑第一个任务："整理当前主流跨链桥的费用结构与风险事件"。
- ✅ 交付：Hermes 环境配置笔记 + 第一份 Agent 研究产出。

### Day 9（08-13）｜把查报价变成可重复的脚本
- 目标：一次性观察 → 可重复查询（工作流化的第一步）。
- 动作：写脚本（Python/TS）调用 LI.FI Quote API，定时抓取 1-2 条固定路由报价，落盘 CSV/SQLite。
- ✅ 交付：可运行的报价抓取脚本 v1 + 第一批数据。

### Day 10（08-14）｜建立证据记录系统
- 目标：所有观察标准化，为后续假设提供弹药。
- 动作：设计证据模板：时间 / 链 / 资产 / 规模 / 路径 / 桥 / 费用 / 预期净收益 / 结果 / 失败原因；把 D4 以来的记录全部入库。
- ✅ 交付：《证据记录模板 v1》+ ≥5 条证据入库。

### Day 11（08-15）｜监控与告警：让一条路由 7×24 帮你盯着
- 目标：从"我去看"变成"它来叫我"。
- 动作：用 Hermes/脚本定时轮询（每 5-15 分钟），定义告警规则：预期价差 − 预估成本 > 阈值时通知（Telegram 或本地日志）。
- ✅ 交付：一条在跑的监控任务 + 告警规则说明（阈值、频率、过滤条件）。

### Day 12（08-16）｜案例研究 #1：一笔成功的跨链套利
- 动作：找一个公开成功案例（共学材料/文章/链上交易），完整还原：触发条件、路径、规模、各项成本、净利、竞争者是谁、为什么是他做成。
- ✅ 交付：《案例拆解报告 #1》（尽量附链上证据）。

### Day 13（08-17）｜案例研究 #2：一笔失败/擦肩而过的套利
- 动作：找失败案例（revert、桥超时、价差消失、被夹），定位是哪个环节断了：发现晚？成本算错？执行慢？
- ✅ 交付：《案例拆解报告 #2》+《踩坑清单 v1》。

### Day 14（08-18）｜周复盘 #2
- 动作：回看监控数据：这几天告警几次？真机会几次、误报几次？调阈值。
- ✅ 交付：周复盘 + 《我的信号管线图 v1》（数据源 → 过滤 → 告警 → 人工核验）。
- 🚦 关卡：至少有一个持续在跑的脚本/任务，且能解释每一次告警的原因。

**本周里程碑**：证据库在转、监控在跑、有正反两个案例拆解。

## 第三周（D15-D21，08-19 ~ 08-25）：从假设到策略——验证 Edge，受控实施

### Day 15（08-19）｜提出自己的套利假设
- 动作：从两周的证据中提炼 2-3 个可检验假设。格式：**在 X 条件下，路径 Y 的价差有 p 概率覆盖全部成本，预期净收益 Z**；每个假设写明验证方法和证伪标准。
- ✅ 交付：《假设清单》（≥2 个，每个可证伪）。

### Day 16（08-20）｜建立成本模型
- 动作：把成本全部模型化：Gas（按链实测）、swap 费、桥费、滑点（按规模的经验曲线）、失败率 × 失败成本、资金占用；输入(路由, 规模) → 输出(预期净收益)。
- ✅ 交付：《成本模型 v1》（表格或脚本）。

### Day 17（08-21）｜历史数据验证
- 动作：用自己积累的报价数据 + 链上历史交易验证假设：价差出现频率、幅度分布、持续时长；样本不够就诚实写"不确定"。
- ✅ 交付：《历史验证笔记》：数据源、样本量、结论（Edge 存在 / 不存在 / 存疑）。

### Day 18（08-22）｜模拟 / Paper Trading
- 动作：不动真钱走全流程：fork 模拟（Tenderly/Anvil）或严格纸面交易，逐步记录"虚拟执行"，与成本模型的预测对比。
- ✅ 交付：完整《Paper Trading 记录》1 份 + 模型偏差分析（偏差 >30% 就回去改模型）。

### Day 19（08-23）｜信号规则固化 + 最小执行原型
- 动作：把验证过的假设写成信号规则：触发阈值、过滤条件、规模上限、失效条件；做最小原型——哪怕只是"告警 → 人工确认 → 执行检查单"的半自动流程。
- ✅ 交付：《信号规则文档 v1》+ 原型说明。

### Day 20（08-24）｜按能力二选一：受控实施 or 继续观察
- **A. 小规模真实执行**（仅当 D15-D19 全部扎实）：金额 ≤ 可全损额度；白名单路径；预设中止条件（Gas 异常/桥拥堵/滑点超限）；只做一笔，全程记录。
- **B. 继续观察**：让信号再跑 24h，统计命中率与误报率。
- 原则：**不确定就选 B**。熊市里，不亏钱本身就是 Edge。
- ✅ 交付：《实施/观察记录》+《风险检查清单》。

### Day 21（08-25）｜毕业复盘：知识图谱与下一步
- 动作：汇编 21 天全部产出；画自己的链上套利知识图谱；给每个策略候选打分（Edge 强度 / 可重复性 / 所需资源）。
- ✅ 交付：《毕业复盘》：① 我的套利知识图谱 ② 策略候选清单（含取舍理由）③ 下一阶段 3 个研究方向。
- 📌 08-26（缓冲日）：补欠账、参加共学毕业交流、把最好的案例/复盘发到共学社群。

**本周里程碑**：至少 1 个经过"历史验证 + 模拟"双重检验的策略结论——不管是"有 Edge"还是"证伪了"，都是成果。
