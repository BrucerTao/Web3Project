# 本地链测试指南

本指南介绍如何使用本地区块链测试 Agentic Wallet 的完整功能。

## 前置要求

- Node.js 18+
- Ganache 已安装（`npm install -g ganache`）

## 配置步骤

### 1. 启动 Ganache

```bash
# 终端 1：启动 Ganache，使用 Monad 兼容的 chainId
ganache --chain.chainId 10143
```

记下输出的第一个私钥：
```
Private Keys
==================
(0) 0x9ba549d204a50344552e61579f776a47c2e8ac5b4dd5f7f0cfd4eaa2c5ea3df8
```

### 2. 配置 .env 文件

```bash
# 本地 Ganache 配置
TEST_RPC_URL=http://127.0.0.1:8545
TEST_PRIVATE_KEY=0x9ba549d204a50344552e61579f776a47c2e8ac5b4dd5f7f0cfd4eaa2c5ea3df8
PRIVATE_KEY=0x9ba549d204a50344552e61579f776a47c2e8ac5b4dd5f7f0cfd4eaa2c5ea3df8
USER_ID=demo-user
```

### 3. 运行测试

```bash
# 方式 1：运行自动化测试脚本（推荐）
npm run test-mcp

# 方式 2：运行交互式演示
npm run demo

# 方式 3：使用 CLI 工具
npm run cli -- init
npm run cli -- register-agent --name "test-agent" --daily 50
npm run cli -- request-payment --session <session-id> --to <address> --amount 0.01 --reason "test"
npm run cli -- logs

# 方式 4：启动 Web UI（浏览器可视化）
npm run ui
# 浏览器访问 http://127.0.0.1:3847/
```

## 测试内容

测试脚本会执行以下操作：

1. ✅ 列出可用的 MCP 工具（9 个）
2. ✅ 获取钱包信息（地址、余额）
3. ✅ 注册 Agent 并创建 Session Key
4. ✅ 列出所有策略
5. ✅ 验证策略配置（单笔上限、每日预算等）

## 数据持久化

**审计日志存储结构：**
```
data/
└── <钱包地址>/
    └── audit-logs.json
```

**特性：**
- 审计日志自动保存到本地 JSON 文件
- 不同钱包地址的数据完全隔离
- 重启应用后自动恢复历史记录
- `data/` 目录已在 `.gitignore` 中，不会被提交

**验证持久化：**
```bash
# 查看数据目录
ls -la data/

# 查看特定钱包的审计日志
ls -la data/0x.../
cat data/0x.../audit-logs.json
```

## 连接到 Monad 测试网

如果你想测试真实的 Monad 测试网：

```bash
# 1. 更新 .env
TEST_RPC_URL=https://testnet-rpc.monad.xyz
TEST_PRIVATE_KEY=你的真实钱包私钥

# 2. 确保钱包有测试币
# 访问 https://testnet.monadscan.com/faucet 领取

# 3. 运行测试
npm run test-mcp
```

## 常见问题

### "无法连接到本地节点"

确保 Ganache 正在运行：
```bash
lsof -ti:8545  # 应该返回进程 ID
```

### "PRIVATE_KEY is required"

检查 `.env` 文件中是否设置了 `TEST_PRIVATE_KEY` 或 `PRIVATE_KEY`。

### "余额不足"

Ganache 默认每个账户有 10000 ETH。如果是 Monad 测试网，请确保已从水龙头领取测试币。

### "如何查看审计日志"

```bash
# 方式 1：使用 CLI
npm run cli -- logs

# 方式 2：直接查看 JSON 文件
cat data/0x.../audit-logs.json

# 方式 3：在 Web UI 中查看
# 浏览器访问 http://127.0.0.1:3847/
```
