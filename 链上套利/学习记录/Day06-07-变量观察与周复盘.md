## 4. 四条结论（小报告正文）

1. **主流稳定币路线没有冲击拐点**：$1k–$500k 损耗恒定 0.223%。USDC 主路线上价格冲击不是约束；约束是桥容量与费用地板。**推论：稳定币跨链 = 费用+延迟的游戏；冲击是长尾资产的主战场（但伴随代币风险）**——策略定位由此清晰。

## 名词科普（2026-08-16 补充）

- **widget（小组件）**：可嵌入任意网站的"迷你换币窗口"。学员 8/10 截图里 "Powered by LI.FI" 的界面即 LI.FI widget。类比：摆进别人店里的售货机——店面只提供场地，货与定价来自售货机公司。三种渠道之一（另两种：裸 API、直连桥）。
- **Bungee**：Socket 协议的面向用户产品（前端桥站）。Socket 是引擎/协议，Bungee 是门面；招牌功能 refuel = 跨链顺带送一点目标链 Gas。其 API 需 key，故对比作业走手动 widget。
- **eco**：桥名。意图型快桥：声明意图、目标链中继方垫资，秒级。实测中小规模常居最便宜（7s），$500k 时退出前三 = 容量上限。
- **polymer**：桥名。把 IBC（Cosmos 生态的跨链通信标准）引入以太坊 L2 的桥；菜单里常扮演"慢但便宜"（1080s）。
- **E001/E007（证据编号）**：证据库 evidence/evidence-log.md 的流水号，E=Evidence。E001=首条（8/9 池价 vs CEX −0.176% 带内）；E007=Relay 直连 0.010%。编号目的：策略文档可"见 E007"式引用，判断皆可溯源。
- 桥族速记复现：relay（秒级金库型）、across（意图型代表）、squid（Axelar 系）、mayan（Solana↔EVM 见长）、stargate（LayerZero 系）、celer/circle（走 Circle 销毁-铸造官方通道）。
- **solver/意图**：你只声明想要的结果，专业玩家（solver/relayer）竞标垫资实现；秒级跨链的底层机制。

**Q2（追问）：意图族真这么多？逐个详解+例子；垫资失败了怎么扣钱怎么执行？**

1. "意图族"是行为分类（秒级+垫资）非官方标签；各家约束机制不同。
2. 五家：across（乐观预言机 UMA 校验中继方声明，挑战期防欺诈；例 Alice OP→Arb 3秒到账）；relay（deposit 进托管合约+自担风险模型：小额秒付大额等确认/拆单=容量天花板微观来源；托管合约有退款逻辑）；near=NEAR Intents（solver 质押保证金，不交付=slash；支持异构链，例 Carol BTC→Arb ETH）；eco（行为同族：7s/中小最便宜/$500k 消失；内部机制公开少→不理解的桥仓位打折）；lifiIntents（LI.FI 的意图拍卖层，广播意图选最优 solver 报价）。
3. 垫资逻辑四步：①用户存钱进 escrow（义务到此为止）②中继方见 escrow 才垫付（信合约不信人）③凭目标链付款证明领取存款 ④争议在"中继方 vs 协议"间解决（UMA/保证金/挑战期），不波及用户。
   三种失败：存款失败→意图不生效只亏 Gas；中继不垫→超时原路退款；源链重组/欺诈→争议机制处理，用户已收款通常不被追回。
   比喻：先押款到平台托管、快递员见押款秒送货；快递员的风险（重组/库存/延迟）由那 0.01-0.05% 保费补偿；其风控手段（限额/等确认）= 观察到的容量上限与大额切慢桥。

**Q3（追问）：金库/协议族五家的区分+例子**

总区别：意图族=有人垫钱；此族=没人垫钱、钱或凭证真的在动→慢，但"你信谁"各家不同。
- stargate（LayerZero系）：两地联保银行；A链存、B链池放，事后池间再平衡；信 LayerZero+池子偿付；例 Alice 1万USDC 几分钟。
- squid（Axelar系）：自带海关的物流公司；独立验证者网络锁/解锁，swap+bridge+swap一单到底；信验证者群体。
- polymer：外交护照互认；IBC 轻客户端密码学互验，无第三方；信数学；最慢(~18min)信任最小。
- celer·circle：央行销毁-重印；Circle CCTP 源链burn目标链mint，无池无包装币；信 Circle；USDC 桥风险最小的一种。
- mayan：专线换汇行家；专攻 Solana↔EVM（跨VM）；横跨两族（快=relay垫付3s，慢=MCTP 900s）。
对比=信任光谱：信资本→信池子→信验证者群体→信数学/信发行商；信任假设越小通常越慢越受限（桥的不可能三角：速度×安全×通用性）。
实战：检查表"桥风险"项要写成"这笔走X桥，我信的是Y"；信 Circle 与信三月新桥，仓位应不同。

**Q4（追问）：Uniswap 的角色？属于哪条链？L1/L2/L3 是什么、各有哪些链？**

1. Uniswap 角色 = 出发端换币所（同链 swap，解决"资产不对"）；Axelar = 搬运工（cross，解决"链不对"）。出发资产已是目标资产则 swap 步消失。
2. Uniswap 不是链是多链部署的应用（连锁店多分店，各分店独立池子独立价格=②套利来源）。资金在哪条链就用哪条链上的部署；Bob 钱在 Base 则用 Base 分店。"主网"=以太坊 L1 本体；Base 是另一条链（L2），安全最终来自主网。
3. L1/L2/L3 = 法院体系比喻：L1 最高法院（自有共识与安全：Ethereum/Bitcoin/Solana/Avalanche/Near/Sui/Monad）；L2 高级法院（批量执行+摘要上报L1，Gas 便宜几十倍：Arbitrum/Optimism/Base/zkSync/Starknet/Scroll/Linea/Blast/Polygon zkEVM/Mantle/Zora/World Chain）；L3 地方专门法院（建于L2之上的定制应用链：XAI/Rari/Proof of Play=Arbitrum系，Degen Chain=Base系）。L2 便宜=打包摊L1存档费；L3 信任链更长提款更慢。边界模糊（Polygon PoS 侧链/L1 之争、比特币L2）→ 抓本质：安全最终来源+汇报层数。
4. 套利含义：层数多=湖多=价差多；L2/L3 Gas 便宜利好小额；L2→L1 提款慢（乐观系~7天）→ 库存再平衡慢、⑥与占用更大。层数是成本变量。

**Q5（作业2补充）：Bungee 逻辑**
- Bungee = Socket 协议门面；Socket = 聚合数十座桥的跨链路由协议；与 LI.FI 同业竞争。
- 流程：选链/资产/量 → 后端返多路线（最快/最便宜标签）→ 签名(approve+存入Socket合约) → 源链交给所选桥 → 目标链放款。

- API 需 key（实测 401）；LI.FI 免 key = 开发者生态策略差异。研究用手动 widget 足够。
