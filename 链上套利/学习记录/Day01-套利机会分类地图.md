## 0. 统一框架：任何"价差"都先问三个问题

所有套利机会，都可以拆成同样三个问题：

1. **错位从哪来** —— 谁制造了这个价差？（大单交易流 / 桥的摩擦 / 恐慌事件 / 预言机滞后 / 流动性结构性割裂）
2. **时间窗口多长** —— 毫秒级？秒级？分钟级？小时级？
3. **执行摩擦多大** —— Gas / 协议费 / 桥费 / 滑点 / 延迟 / 风险溢价

> **价差 − 摩擦 = 净收益。** 摩擦之内的价差叫"无套利带"，它不是机会，是噪声。

另一条贯穿所有类型的分界线：**原子 vs 非原子**。
- **原子**（同一区块内完成，常用闪电贷）：无库存风险，纯拼速度 → 被专业机构垄断。
- **非原子**（跨区块/跨链，需要库存或过桥）：有时间窗口，拼成本建模与风险管理 → 个人有空间。

## 1. 七大机会类型

### ① DEX 内套利（同池价格偏离）
- **一句话原理**：AMM 的价格 = 储备量的函数。一笔大单成交后，池内价格偏离市场公允价；套利者把它推回去，赚取差价。这是 AMM 最基础的套利形态。
- **谁在付钱**：池子 LP（逆向选择成本）+ 大单发起者。
- **时间窗口**：毫秒～秒级（下一个区块内）。
- **所需能力**：mempool 监控、Gas 竞价、Flashbots/bundles、闪电贷。
- **典型 Edge**：单笔几十～几千美元，频率极高。
- **主要风险**：交易失败白付 Gas、竞价输给对手。
- **竞争烈度**：★★★★★，顶级 searcher 的主场。
- **个人可行性**：☆（主网）；新链/长尾池偶有缝隙，窗口期很短。

### ② DEX 间套利（同链跨所）
- **一句话原理**：同一交易对在 A 所便宜、B 所贵；低买高卖，同块原子完成。
- **谁在付钱**：两边池子的 LP + 滞后的流动性提供者。
- **时间窗口**：区块级。
- **所需能力**：多 DEX 路由、原子合约、Gas 竞争。
- **典型 Edge**：价差被压到几个 bp，净利常为几十～几百美元。
- **主要风险**：同①；另有路由执行滑点。
- **竞争烈度**：★★★★★，聚合器（1inch/CoW 等）与 searcher 已吃掉大部分。
- **个人可行性**：☆。

### ③ 三角套利
- **一句话原理**：A→B→C→A 三条（或多条）汇率不一致，走一圈回来 A 变多。
- **谁在付钱**：路径上各池子的 LP。
- **时间窗口**：区块级。
- **所需能力**：图搜索（Bellman-Ford 找负环）、原子执行、闪电贷放大规模。
- **典型 Edge**：个位数 bp，靠规模。
- **主要风险**：执行竞争、滑点侵蚀。
- **竞争烈度**：★★★★★。
- **个人可行性**：☆。

### ④ 跨链套利 ⭐ 本次共学主战场
- **一句话原理**：同一资产在不同链上定价不同；便宜链买入、昂贵链卖出。摩擦（桥费 + 双边 Gas + 延迟）形成较宽的"无套利带"，**突破带的价差才是机会**。
- **错位来源**：桥的摩擦、流动性割裂、局部大单、各链 Gas 币/稳定币供需失衡。
- **时间窗口**：分钟～小时级 —— **这正是个人能够得着的窗口**。
- **两种玩法**：
  - **库存模式**：两链预持资产，贵侧卖、贱侧买，之后慢慢再平衡。不抢桥的延迟，但承担库存敞口 + 桥安全风险。
  - **发现模式**：先发现价差，再通过 LI.FI 跨链执行。无库存压力，但价差可能在过桥期间消失。
- **所需能力**：跨链报价监控（LI.FI Quote API）、桥成本与延迟建模、库存管理。
- **典型 Edge**：几十 bp 到几个百分点，但必须扣桥费 + 双边 Gas + 滑点。
- **主要风险**：价差在途中消失、桥故障/超时、滑点、Gas 波动、库存贬值。
- **竞争烈度**：★★★☆☆ 中等 —— 非原子、竞争分散，成本建模能力决定胜负。
- **个人可行性**：★★★☆☆ **相对可行**，尤其小资金规模（大资金会自己把价差吃平）。

### ⑤ 稳定币脱锚套利
- **一句话原理**：稳定币偏离 $1：折价时买入，通过赎回通道按 $1 兑付，或赌 peg 修复。
- **历史案例**：2022 UST 崩盘；2023 SVB 事件中 USDC 短时跌至约 $0.87 后修复。
- **谁在付钱**：恐慌抛售者；或发行方储备/赎回机制。
- **时间窗口**：小时～天级（事件驱动，罕见）。
- **所需能力**：事件监控、理解兑付通道（发行方/CEX/链上池）、仓位纪律。
- **典型 Edge**：大（1%–10%+），频率低。
- **主要风险**：**这次真的不回来**（信用风险）、赎回通道冻结、流动性枯竭。
- **竞争烈度**：★★★☆☆，拼风险承担能力而非速度。
- **个人可行性**：★★☆☆☆ 可小资金参与，前提是读懂发行方储备与赎回机制；永不上杠杆。

### ⑥ 清算
- **一句话原理**：借贷协议（Aave/Compound/Maker 等）抵押率跌破清算线，清算人代偿债务、折价获得抵押品（奖励通常 4%–15%）。
- **谁在付钱**：被清算的借款人（清算罚金）。
- **时间窗口**：区块级（健康因子越线瞬间）。
- **所需能力**：健康因子监控、闪电贷原子闭环、Gas 竞价、抵押品卖出通道。
- **典型 Edge**：奖励固定，扣 Gas 与滑点后很薄。
- **主要风险**：交易失败、抵押品价格继续下跌（不用闪电贷时）。
- **竞争烈度**：★★★★★ 专业清算机器人。
- **个人可行性**：☆（长尾协议/新链略有缝隙）。

### ⑦ MEV（三明治 / 尾随 / 抢跑）
- **一句话原理**：赚交易排序权的钱。尾随（backrun）= 跟在大单后吃价差（①②的变体）；三明治 = 夹击用户大单；抢跑 = 复制他人高收益交易。
- **谁在付钱**：尾随——LP/滞后者；三明治——被夹用户的滑点（道德争议大，被多数钱包与协议主动拦截）。
- **时间窗口**：区块级。
- **所需能力**：mempool 监控、私有通道（Flashbots/MEV-Blocker）、bundles、Gas 竞价。
- **典型 Edge**：差异极大；尾随机会已被聚合器大幅压缩。
- **主要风险**：失败成本、声誉与合规风险（三明治）。
- **竞争烈度**：★★★★★ 寡头化（顶级 searcher + builder 联盟）。
- **个人可行性**：☆。

## 3. 关键问题的回答：个人到底能做什么？

**原子型（①②③⑥⑦）对个人基本关闭。** 逻辑链：无库存风险 → 纯拼速度 → 速度被资本化为 Gas 竞价与基础设施投入 → 头部玩家有规模效应。你不是在和人竞争，是在和一个产业竞争。

**个人的空间在"慢机会"：**
1. **跨链套利（④）**——摩擦厚（桥 + 双边 Gas + 延迟）、窗口长、竞争分散，**成本建模能力决定胜负**。这正是 LI.FI 的地盘，也正是本次共学的主线。
2. **稳定币脱锚（⑤）**——事件驱动，拼研究深度与风险承担而非速度；小资金 + 深度理解可行。

因此我们的策略：**④ 为主线，⑤ 为观察位，①②③⑥⑦ 只做认知理解**——知道它们为什么被垄断，本身就是地图的一部分。

## 6. 答疑记录（2026-08-09）

**Q：为什么原子型（①②③⑥⑦）不适合个人，属于"和一个产业竞争"？为什么 ④⑤ 就可以？**

**原子型被垄断的四步逻辑链：**
1. 原子套利 ≈ 无风险利润 → 无风险利润会被瞬间抢平，利润压缩到"执行成本 + 一根毛"；
2. 胜负只剩速度，而速度要花钱（自建节点、机房托管、私有通道、Gas 极致优化），且是固定成本，有规模效应——你骑摩托，对面是车队 + 专用高速公路；
3. 多人撞见同一机会时互相抬 priority fee（PGA 竞价），利润大部分作为 Gas 付给验证者，赢家只拿一根毛，输家白付 Gas；
4. 行业已形成流水线：searcher 找机会 → builder 打包 → validator 排序，头部机构 7×24 全职优化。个人 = 下班写脚本 vs 全年无休的产业流水线。

**④⑤ 适合个人的原因（核心反转：因为有风险，所以有空间）：**
1. 风险是护城河：库存敞口、桥风险、脱锚不归零风险，让风险厌恶的大资金主动退出，竞争密度骤降；
2. 窗口长，拼认知不拼速度：分钟～天级窗口，比的是成本模型算得准不准、桥懂得深不深、恐慌时敢不敢下手；
3. 小资金反而灵活：价差容量小，大资金进场自己就把价差砸没，机构看不上小额"碎屑"——大资金捡西瓜，个人捡没人捡的芝麻；
4. 摩擦厚 = 门槛：桥费 + 双边 Gas + 延迟 + 滑点算清楚，本身就筛掉 90% 的人。

**注意**：④⑤ 不是安全区，是把竞争从"速度军备竞赛"换成"认知竞赛"。桥塌、脱锚归零、价差中途消失是必须管理的风险——这正是 Day 15-20（成本模型/历史验证/Paper Trading）存在的意义。

**比喻存档**：原子套利 = 公开跑道上百米冲刺捡钱（拼不过职业选手）；跨链/脱锚套利 = 进深山采松茸（路远有风险，但职业选手在平地抢金条，大卡车上不了小路，步行背篓的人反而吃得开）。

**Q2（追问）：能不能给真实案例和交易链路？概念太抽象。**

### 案例 A｜⑦ 三明治工业化：jaredfromsubway.eth
- EigenPhi 统计：不到 3 个月流水 $40.6M、净利 $6.3M；一度是全以太坊 Gas 消耗最大的地址，每天自动执行数千笔。
- 单笔链路：用户大单进公开内存池 → 机器人算出该单将推高价格 ~1.5% → 构造 [抢跑买入 → 用户单 → 尾随卖出] bundle，经 Flashbots 私有通道 + 贿赂交给验证者 → 同块按序执行 → 用户的滑点变成机器人的利润。
- 2026-06 反转：该机器人被蜜罐交易钓鱼，一次亏损 $7.5M（The Block/Cointelegraph 报道）。军备竞赛里连头部玩家都被猎杀，个人进去是当猎物。

### 案例 B｜⑥ 清算资本战争：MakerDAO 黑色星期四（2020-03-12）
- ETH 24h 暴跌 ~45%，Gas 天价、网络拥堵，MakerDAO 近 4,000 个仓位被清算。
- 链路：清算拍卖允许 0 DAI 出价 → 一个机器人批量提交 0 DAI 竞价（成本仅 Gas）→ 网络拥堵使无人能加价 → 计时结束，0 DAI 收走真实 ETH，重复数百次。
- 结果：$8.32M ETH 被 0 DAI 拍走，协议背坏账约 $4.5M–$5.7M（口径不一）。事后 MakerDAO 改机制（禁零出价、延长拍卖）。
- 教训：机会全世界都看见了，但只有基建最硬、敢烧 Gas 的玩家能把交易送进去。

### 案例 C｜①② 原子套利标准链路（Flashbots 文档经典结构）
闪电贷 1,000 ETH → 便宜池买入 → 昂贵池卖出 → 还贷留差价；若利润覆盖不了成本则整笔回滚（只损失 Gas）→ 经 Flashbots bundle + 贿赂同块完成（全程 ~12s）。
- 闪电贷使本金门槛归零 → 零门槛 → 所有人扫同一批机会 → 利润被竞价压到只剩 Gas + 贿赂。
- 佐证：arXiv《Atomic Execution is Not Enough for Arbitrage Profit Extraction》（原子执行权也不保证利润）；Flashbots L2 MEV 仪表盘显示原子套利是最大 MEV 类别，由少数职业 searcher 执行。

### 案例 D｜⑤ USDC 脱锚周末（2023-03-10 ~ 03-13）
- 时间线：3/10 SVB 被接管（Circle $3.3B 储备在 SVB）→ 3/11 USDC 链上最低跌至约 $0.87，Circle 周末暂停铸造/赎回（赎回通道冻结）→ 周末成交 $2.8B、约 $2B 逃离 DeFi → 3/13 美联储全额保障 SVB 存款，USDC 数小时修复至 $0.99。
- CoinDesk + CryptoQuant 链上复盘：一个钱包靠这波交易一天赚约 $16.5M。
- 套利链路：研究判断（FDIC 兜底 + Circle 储备多为美债 → 回不来的概率低）→ 恐慌抛售中 $0.88–0.95 接盘 → 持有过周末（承担信用风险）→ 修复后退出。
- 教训：窗口持续整个周末（小时～天级），拼研究、判断与风险承担，不拼速度。$16.5M 大头归有银行通道的交易公司，但同构机会在此后小型脱锚中反复出现（2023-07 Curve 事件、USDe 等），小资金可参与。

### 案例 E｜④ 跨链套利的学术实测
- Gogol et al. 2024（arXiv 2406.02172，MEV-SBC '24）：Dencun 后 L2 间非原子套利实测——价格错位持续数秒至数分钟；套利潜力约为 Arbitrum/Base/Optimism 交易量的 0.03–0.05%，ZKsync 约 0.25%。
- ACM 2025《Cross-Chain Arbitrage: The Next Frontier of MEV》：2023.9–2024.8 一年、9 条链测量，确认跨链套利因非原子而未被 searcher 产业吃干净。
- 典型链路：LI.FI Quote API 监控跨链价差 → 价差突破无套利带（桥费 + 双边 Gas + 滑点 + 风险溢价）→ 便宜侧买入 → 过桥（分钟～小时，价差可能收窄 = 非原子性收的"风险税"）→ 昂贵侧卖出 → 再平衡。

### 小结
- 原子型竞争形态 = searcher→builder→validator 产业流水线（7×24）；非原子型 = 监控→成本模型→风险承担（个人可闭环）。
- 比喻保留：原子套利 = 公开跑道百米冲刺捡钱（拼不过职业队，冠军还被猎人盯上）；跨链/脱锚 = 进深山采松茸（职业队在平地抢金条，大卡车上不了小路，步行背篓者反而吃得开）。

**Q3（追问）：案例里的名词解释：Uniswap ↔ SushiSwap、MEV、Flashbots、bundle、searcher→builder→validator**

1. **Uniswap ↔ SushiSwap**：两家 DEX（跑在链上、无公司运营的交易所）。Uniswap 最老最大（2018），SushiSwap 2020 年复制其代码靠发币挖走用户（"吸血鬼攻击"）。两家卖同样的币但各有独立资金池，池内价格由各自供需决定 → 大单砸偏一个池子，两池出现价差 → 套利来源。比喻：同城两个菜市场，大买家把 A 市场白菜买贵了，跑腿的在 B 买 A 卖。

2. **MEV（Maximal Extractable Value）**：区块内交易顺序会改变结果，谁能决定"谁先谁后、能否插队"，谁就能把排序权变现（尾随/三明治/清算抢先等）。仅以太坊累计被提取的 MEV 已达数亿美元量级（Flashbots MEV-Explore）。比喻：缴费长队本应先到先得，管排队的人靠插队、调序、截胡赚的钱。

3. **bundle**：一捆指定顺序、"要么全成要么全废"的交易包。三明治 bundle = [机器人买入, 用户大单, 机器人卖出]，保证机器人不会买了卖不掉。走私有通道提交，防抄作业。比喻：餐厅套餐单，任一道没货整桌取消。

4. **Flashbots**：2020 年成立的研究组织，把 MEV 竞争从"公开内存池里 Gas 竞价（输家烧钱、交易被抄）"改造成"私有通道密封竞拍（searcher 私密提交 bundle + 出价，验证者挑最高价，输家不亏）"。副作用：竞争更工业化、个人门槛更高。普通人可用其私有通道防三明治。

5. **searcher → builder → validator（PoS 后的三段流水线）**：
   - searcher（猎手）：脚本全网扫机会（价差/可夹用户单/可清算仓位），jared 即其顶级产品；
   - builder（打包商）：收集海量 bundle，计算最优拼块方案，向验证者出价竞拍；
   - validator（记账人）：质押 32 ETH 的出块节点，多不自己做 MEV，选最高价的块。
   - 钱流向：searcher 发现金子 → bundle 给 builder → builder 拼块出价 → validator 选最高价；利润大头以出价形式上交（采矿权费拿走大头）。
   - 集中度：少数头部 builder 产出以太坊绝大多数区块（MEV-Boost 中继公开统计）——"和产业竞争"的字面含义。

6. **关键连接**：builder 只能打包一条链的区块；跨链套利（④）横跨两条链，塞不进同一区块、做不成 bundle → 流水线物理上够不到它 → 这是 ④ 未被产业吃干净、个人仍有空间的结构性原因。

**小词典**：mempool = 交易候机大厅（公开可见，黑暗森林所在）；Gas/priority fee = 手续费 + 插队小费；闪电贷 = 同块借还、还不就回滚的贷款，原子套利的零本金来源。

**自检题第 3 题作答与批改（2026-08-09）**

作答：Gas $2 ÷ $1,000 = 0.2%；摩擦合计 0.2% + 0.05% + 0.1% = 0.35%；价差 0.8% − 0.35% = 净利 0.45% → 判定有机会。
批改：**算式全对 ✓**（固定成本折算百分比这一步做对了）；结论修正为"**纸面候选机会**"。三个暗门：
1. 规模敏感性：Gas 固定 $2 → 本金 $200 时 Gas 占 1%，摩擦 1.15% > 0.8%，不是机会；本金 $10,000 时滑点会随规模长大，0.1% 不再成立。每个机会有"可行规模带"。
2. 风险税：0.45% 未折价。真实期望 = p(价差存活) × 净利 − p(消失) × 沉没成本（桥费+Gas 已付出）；过桥期间还承担资产自身价格敞口。
3. 绝对金额：$4.5 单笔价值低，要靠频率与规模测试判断能否成为策略——单笔报价是点，持续监控才是线。
