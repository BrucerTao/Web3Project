# Monad Agentic Payment - 参赛说明文档

## 项目概述

**Monad Agentic Payment** 是一个为 AI Agent 设计的原生安全支付系统，构建在 Monad 链上。它解决了"Agent 可以行动，但不能失控"的核心问题，使 AI Agent 能在用户授权下自主完成链上支付，同时确保安全、可控、可审计。

## 核心创新点

### 1. Agent 原生设计（非人类钱包）

传统钱包假设操作者是人，而本系统专为 Agent 设计：

- **Session Key 临时授权**：Agent 不持有主私钥，仅使用受限的临时密钥
- **任务上下文支付**：每笔支付关联 Task ID、Agent ID、原因说明
- **自动失效机制**：Session Key 到期自动失效，无需手动撤销

### 2. 策略引擎（Policy Engine）

可配置的安全策略层，支持：

```typescript
{
  maxSinglePayment: 10,    // 单笔 $10 上限
  dailyBudget: 50,         // 每日 $50 预算
  requireHumanAbove: 5,    // 超过$5 需要人工确认
  allowedRecipients: [...], // 白名单地址
  blockedMethods: [...],    // 禁止的支付类型
}
```

### 3. 分级审批系统

- **小额自动**：< $5 自动执行
- **中额二次确认**：$5-$10 需要用户确认
- **高风险人工**：> $10 或触发黑名单直接拒绝

### 4. 完整的审计日志

每笔支付记录包含：
- Task ID, Agent ID, Session ID
- 收款方、金额、原因
- 命中的策略规则
- 风险等级（low/medium/high/critical）
- 是否人工确认
- 执行结果（TX Hash）

**数据持久化**：
- 审计日志自动保存到 `data/<钱包地址>/audit-logs.json`
- 不同钱包地址的数据完全隔离
- 重启应用后自动恢复历史记录
- 支持导出 JSON/CSV 格式


```bash

# 终端 2：运行 MCP 测试

```

### 4. 运行演示

```bash
npm run demo
```

### 5. 使用 CLI

```bash
# 注册 Agent
npm run cli -- register-agent --name "coding-assistant" --daily 50

# 请求支付
npm run cli -- request-payment --session <id> --to <address> --amount 0.01 --reason "API"

# 查看审计日志
npm run cli -- logs
```

### 6. 启动 MCP Server（在 Claude Code 中使用）

```bash
npm run mcp
```

在 Claude Code 配置中添加：

```json
{
  "mcpServers": {
    "agentic-wallet": {
      "command": "npx",
      "args": ["tsx", "src/mcp-server.ts"],
      "cwd": "/path/to/monad-agentic-payment",
      "env": {
        "TEST_RPC_URL": "http://127.0.0.1:8545",
        "TEST_PRIVATE_KEY": "你的私钥"
      }
    }
  }
}
```

详细配置见 [MCP 使用指南.md](./MCP 使用指南.md)

## 使用示例

### SDK 方式

```typescript
import { AgenticWallet } from 'monad-agentic-payment';
import { Wallet } from 'ethers';

// 初始化
const wallet = new Wallet(process.env.PRIVATE_KEY!);
const agenticWallet = new AgenticWallet({ ownerWallet: wallet });

// 注册 Agent（自动创建 Session Key 和策略）
const { agent, sessionKey, policy } = agenticWallet.registerAgent(
  'My Assistant',
  'assistant',
  {
    policy: { maxSinglePayment: 10, dailyBudget: 50 }
  }
);

// Agent 请求支付
const result = await agenticWallet.requestPayment(
  sessionKey.id,
  '0x...',
  0.005,
  'API payment'
);

if (result.success) {
  console.log('支付成功:', result.result?.txHash);
} else if (result.requiresHumanApproval) {
  // 人工确认
  await agenticWallet.approvePayment(result.auditLogId!, true);
}
```

## 安全特性详解

### 1. 私钥安全

- **主私钥**：用户持有，仅用于最终签名
- **Session Key**：临时密钥，权限受限，到期失效
- **Agent 无法**：接触主私钥，仅能通过 Session Key 在策略范围内行动

### 2. 策略检查流程

```
支付请求
   │
   ▼
┌─────────────────────┐
│ 1. 验证 Session Key  │ ← 是否有效/未撤销/未过期
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│ 2. 策略检查         │ ← 单笔限额、每日预算、白名单
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│ 3. 风险评级         │ ← low/medium/high/critical
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│ 4. 审批决策         │ ← 自动/人工确认/拒绝
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│ 5. 执行支付         │ ← 发送交易
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│ 6. 审计记录         │ ← 完整日志
└─────────────────────┘
```

### 3. 紧急撤销

用户可随时撤销：
- 单个 Session Key
- 整个 Agent 的所有权限
- 撤销后立即失效，无法继续使用
