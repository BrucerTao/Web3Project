> 建议用时：2 小时

## 1. AMM 没有订单簿：你在和"池子"交易

中心化交易所（CEX）是订单簿：买家挂单、卖家挂单，撮合成交。
AMM（自动做市商）完全不同：

- **LP（流动性提供者）** 把两种资产按一定比例存进一个**池子**（如 10 ETH + 20,000 USDC），换取手续费分成；
- **交易者** 不找对手方，直接把一种资产塞进池子、从池子里拿走另一种——**池子就是你的对手方**；
- **价格不由人报，由池子的储备量算出来**。

所以 AMM 的价格 = 池子当前状态的函数。有人交易，储备变，价格立刻变。

## 2. x*y=k：价格是怎么"算"出来的

最经典的 Uniswap v2 规则：**池子里两种资产储备量的乘积恒定**。

> x（ETH 数量）× y（USDC 数量）= k（常数）

交易规则：你往池子里放 ΔX，池子必须给你 ΔY，使得交易后乘积仍然等于 k。

**ETH 的"价格"就是储备比**：P = y / x。

### 例 1：小池子（10 ETH + 20,000 USDC）

- k = 10 × 20,000 = 200,000；现货价 = 20,000 ÷ 10 = **$2,000/ETH**
- 有人要**买 1 个 ETH**：池子 ETH 变为 9，为保持 k 不变，USDC 必须变成 200,000 ÷ 9 = **22,222.22**
- 买家要付：22,222.22 − 20,000 = **$2,222.22**
- 成交均价 $2,222.22，比现货贵 **+11.1%** —— 这就是**价格冲击（price impact）**
- 成交后池子的新现货价：22,222.22 ÷ 9 = **$2,469**（+23.5%）—— 这是下一笔交易面对的价格

### 例 2：大池子（1,000 ETH + 2,000,000 USDC，同样 $2,000）

- k = 2,000,000,000
- 买 1 个 ETH：ETH → 999，USDC → 2,000,000,000 ÷ 999 = 2,002,002
- 成本：**$2,002**，均价 +0.10%；新现货价 $2,004（+0.20%）

**同样买 1 个 ETH：小池子 +11.1%，大池子 +0.10%。差 100 倍。**

### 三条关键结论

1. **价格冲击只取决于你"吃掉池子储备的比例"，与绝对金额无关。** 公式：冲击 ≈ f ÷ (1−f)，f = 买走的量 ÷ 池子储备。吃 10% → 11.1%；吃 0.1% → 0.1%。
2. **区分两个价格**：成交均价（你这笔实际付的）和边际价格（成交后池子的新报价）。套利者看边际价格决定要不要继续搬。
3. **池子越深，越难被推动。** "流动性深度"就是池子的抗冲击能力——这正是 LI.FI 报价里"规模越大、单价越差"的底层原因。

## 3. 手续费：无套利带的又一层

- Uniswap v2 每笔 swap 收 **0.3%** 手续费（给 LP）；Uniswap v3 有 0.01%/0.05%/0.3%/1% 多档；Curve 稳定池常为 0.04%。
- 套利者要把偏离的池子搬回公允价，得先覆盖手续费：**同链 DEX 间套利要同时付两个池子的手续费**（0.3%+0.3%=0.6%）。
- 所以：手续费越高的池子，允许的偏离越大、越持久——**手续费直接加宽无套利带**（呼应 Day 1 的核心公式：价差 − 摩擦 = 净收益）。

## 4. 三种池子结构（对套利者意味着什么）

| 结构 | 机制 | 对价格/套利的含义 |
|---|---|---|
| **Uniswap v2** | 流动性均匀铺满整条 x*y=k 曲线 | 简单直观；资金效率低 |
| **Uniswap v3 集中流动性** | LP 把流动性集中在自选价格区间 [pa, pb]；区间内等效于一个"放大版的池子"，价格出区间则资产全部变成另一种 | 区间内深度大、价格紧贴外部市场 → 偏离更小更短；套利竞争更激烈。LI.FI 的报价引擎要同时路由几百个这样的池子 |
| **Curve Stableswap** | 专为"价格相近的资产"（USDC/USDT/DAI）设计，曲线在 1:1 附近平坦 | 巨额交易冲击极小（百万美元级 swap 只有几个 bp）；但**一旦脱锚，曲线迅速变陡，流动性"抽走"** —— 这正是 USDC 周末、UST 崩盘时价格加速雪崩的机制（案例⑤的放大器） |

## 5. 区块确认与最终性：每条链有自己的"钟"

- **以太坊**：12 秒一个块；交易被打包（软确认）很快，但**最终性（不可回滚）约 12.8 分钟**（两个 epoch）。
- **L2（Arbitrum/Base 等）**：亚秒级软确认，欺诈证明/挑战窗口（约 7 天）才到硬最终性。套利实际依赖的是软确认——"能马上被下一笔交易看见"。
- **L2 排序规则**也在演化：Arbitrum 从先到先得（FCFS）演进出"快速通道拍卖"（Timeboost）——同链抢跑的游戏在 L2 上换了形态继续存在。
- **跨链的关键推论**：每条链是一个独立时钟，价格各自形成；桥是连接时钟的管道，桥的确认时间就是"跨链延迟"这个成本项的物理来源。

## 6. 总结比喻：湖泊与管道

- 每个 AMM 池子是一个**湖**，水位（价格）由自己的储备决定；
- 外部信息（CEX 价格变动、别的链上的大单）是**波浪**，波浪靠套利者凿出的**管道**在湖与湖之间传播；
- **管道的摩擦（手续费 + Gas + 桥延迟）决定了水位拉平的速度**：摩擦大 → 拉平慢 → 价差更大、更持久；
- **同链**：管道很短（一个区块）→ 价差活一个块 → 被产业流水线吃掉（Day 1 案例 A/B/C）；
- **跨链**：管道很长（过桥几分钟到几小时）→ 价差活数秒到数小时（Gogol 论文实测）→ 我们的主战场。

**套利者就是管道本身，管道的摩擦费就是他们的利润。**

## 7. 与 Day 1 的呼应

- Day 3 成本清单里的"滑点/价格冲击"一项，今天有了精确的量化方法（f/(1−f)）；
- 手续费 → 无套利带宽的组成部分；
- 集中流动性与 Stableswap → 解释了不同池子摩擦差异；
- 每条链独立时钟 → 跨链机会的根源。

## 答疑记录（2026-08-09）

**Q1：AMM 针对 DEX 还是 CEX？k 是谁定义的、为何都遵循？池子数量/交易对不同？USDC 可换 USDT？分子分母固定吗，为何不能 USDC/ETH？**

1. **AMM 的适用范围**：AMM 是交易机制设计，是 DEX 的主流基础设施（链上无中介，必须用数学公式定价与结算）；CEX 用订单簿撮合，基本不用 AMM。但 DEX ≠ 必然 AMM（dYdX/Hyperliquid 是链上订单簿）。比喻：CEX = 有拍卖师的集市；AMM = 自动售货机，价格由库存公式自动报出。

2. **x*y=k 的来历**：Vitalik 2016-17 提出，Hayden Adams 2018 年在 Uniswap v1 实现。**它不是行业标准，只是最出名的一个设计**。优点：流动性永不枯竭（储备趋零价格趋无穷）、公式极简、LP 经济可计算。其他曲线：Curve Stableswap（1:1 附近拍平，为稳定币）、Balancer 加权多币池、Uniswap v3 集中流动性。套利者须知：每个池子曲线可能不同，报价引擎必须逐池定价。

3. **池子的独立性与多样性**：每个池子独立、各有各的 k 与价格；光 ETH/USDC 就有几百个池子（不同协议、不同费率档）——这正是 ② DEX 间套利的来源。任意两币可建池，也有多币池（Curve 3pool = USDC+USDT+DAI）。进阶：k 只在交易时不变；LP 存取款改变 k；手续费留在池内使 k 缓慢增长，k 的增长 = LP 收入 = 交易者成本。

4. **USDT 完全可以**：USDT/ETH 池更古老更大；USDC/USDT 本身是最活跃交易对之一。例子里的 USDC 只是占位。

5. **分子分母不固定**：x*y=k 本身对称，无分子分母。"价格"是汇报习惯：计价币储备 ÷ 基础币储备。ETH/USDC=2,000（1 ETH 值 2,000 USDC）与 USDC/ETH=0.0005 是同一事实的倒数，如"1 美元=7.1 元"与"1 元=0.14 美元"。买卖方向 = 同一公式解另一边。

**Q2（追问）：币的总量会变（发行商继续发币），池子里的数量怎么算？算自己的 LP 还是算外部发行商的？**

核心答案：**池子是封闭盒子，只数自己肚子里的币，永不查询发行商或总供应量。**

1. 池子里的数量 = 智能合约地址的真实余额，来自 LP 存入，合约自己记账。储备只有四种变化：swap / LP 存入 / LP 取出 / 手续费累积。发行商在外面铸多少币，只要没人存进池子，池子一个字节都不变。

2. 发行商发币的传导链：铸币进某些人钱包（池子无感知）→ 供应增加压低全市场价格（CEX + 所有 DEX）→ 套利者发现池子价格落后于市场 → 在池子高卖低买，把新价格"搬"进池子。**池子从不查发行商的账，它被动被市场价格推着走；套利者是价格信使。**

3. ETH 特殊：无发行商主体，新增 = 验证者质押奖励（年化约 0.5–1%），EIP-1559 同时销毁手续费，供应时增时减；同步机制相同。

4. 对套利者的两个关键认知：
   - 机会来源：池子对外界无知、只在被交易时更新 → 两笔交易之间外部价格变动而池子停在原地 → 池子的迟钝就是价差的来源（"湖泊与管道"）。
   - 陷阱来源：有些代币会"隔空"改变池内数量——Rebase 代币（余额无转账自动增减）、转账抽税代币（池子实收少于账面）、代币迁移（旧合约归零）。长尾币大价差先查代币机制；jared 被蜜罐钓走 $7.5M 就是此类把戏。

5. 比喻：池子 = 水库（只知自己水位）；发行/销毁 = 流域降雨（改变全市场"河流"水位）；水库不监测降雨，靠套利者这根管道被河水推着走。

**Q3（追问）：不用 AMM 的 DEX 用什么机制？不会亏本吗？没法像 CEX 那样维护订单簿吧？各自怎么维持秩序和盈利？**

1. **非 AMM 的 DEX 三派**：
   - 链上订单簿：挂单撮合全上链（Hyperliquid 自建 L1、dYdX v4 自建应用链、OpenBook/Solana，前身 Serum 随 FTX 倒闭）；
   - 混合式（链下撮合 + 链上结算）：订单是用户签名的密码学消息，存 relayer 服务器撮合，成交才上链，资产不托管（0x、早期 IDEX）；
   - 意图式/RFQ：无持续订单簿，用户签"意图"，职业 solver 竞标成交，每隔几秒批量拍卖（CoW Swap、UniswapX、1inch Fusion）。

2. **秩序怎么维持**：区块链本身就是共享数据库 + 裁判。链上订单簿 = 订单簿写在链上状态，价格/时间优先由协议代码强制执行；混合式 = 订单有签名，服务器改不了，结算仍在链上；意图式 = 用竞标拍卖替代连续撮合。代价是速度与成本：改一次订单簿状态 = 一笔 Gas。

3. **为什么以太坊上 AMM 赢了**：2016-17 的链上订单簿（EtherDelta）死于高 Gas——挂单撤单都要付钱。AMM 一个池子只存两个数字（储备量），成本可忽略。AMM 不是理论更优，是"慢且贵的链"上唯一可行方案。高性能链出现后（Solana、Hyperliquid 专用链），链上订单簿复活。

4. **为什么场所不亏本**：场所只做中立中介赚费用流水，从不承担持仓风险；风险永远在流动性提供者身上。AMM：LP 承担无常损失 + 逆向选择，LP 赚手续费；订单簿：做市商承担报价过时风险，赚价差 + 返佣，场所赚吃单费 − 挂单返佣；意图式：solver 承担成交后波动，赚优化差价。订单簿做市商可撤单可定价（主动），AMM LP 被动挨打——所以职业机构在订单簿做市，散户在 AMM 当 LP。被套利者薅的是 LP/做市商，不是场所——套利者每笔搬运也在付手续费。

5. **与套利的关系**：场所类型不同 = 价格形成机制不同 = 更多的"湖"（AMM 平滑曲线 / 订单簿档位跳变 / 意图式拍卖价）。LI.FI 报价引擎会同时路由这些场所。跨场所套利要对付不同的"物理规律"。

## 手算练习批改（2026-08-09）

**题 1：满分 ✅**
买后 ETH=19，USDC=800,000/19=42,105.26；付款 $2,105.26；均价 $2,105.26；冲击 5.26%（与公式 f/(1−f)=0.05/0.95 一致）；新报价 $2,216.07。

**题 2：半对 ⚠️**
"冲击由买走占比决定"核心正确；但"换大池子=规模变大"因果反了。标准答案：同一个 1 ETH，小池冲击 5.26% vs 大池 0.1%——变的是池子深度不是你的规模。推论：① 交易量必须匹配路径上最浅的池子（机会容量天花板）；② 选路由比的是"算完冲击后的实际成交价"而非表面报价——LI.FI 报价引擎做的就是这件事。

**题 3：方向对、停手点反了 ⚠️**
正确：外面 $2,000 买入，搬进池子 A 卖出。修正：卖出使池子价从 $2,216 下跌；停手点是池子价跌到 ≈$2,006（价差恰覆盖 0.3% 手续费：2,000/0.997≈2,006），不是 $2,216。关键认知：池子不会被搬回 $2,000 整，手续费带在两市场间留下永久的缝——这就是 DEX 价格可长期略偏离 CEX 而无人搬的原因。容量计算：$2,216→$2,006 约可搬 0.97 ETH、总利润 ~$99——同链机会是蚊子腿，且被 searcher 块内原子吃光。

**加分题批改（2026-08-09）：✅ 方程列对**
方程组 (20−y)(40,000+x)=800,000 与 (40,000+x)/(20−y)=2,100 正确；注意是二元二次（非线性），代入后塌缩为 (20−y)²=800,000/2,100=380.95 → 20−y=19.518 → **换回 0.482 ETH，投入 $987.8**。

**Q5（追问）：快捷公式 x_new=√(k/P)、y_new=√(k·P) 怎么来的？用加分题演示。**

推导（就是把手算方程组提前解完）：新储备满足 ① x_new·y_new=k ② y_new/x_new=P。由②得 y_new=P·x_new，代入①：x_new²=k/P → x_new=√(k/P)；同理 y_new=√(k·P)。

加分题逐步计算（k=800,000，P=2,100）：
1. x_new = √(800,000/2,100) = √380.952 ≈ 19.518 ETH（估法：19.5²=380.25，微调）
2. y_new = √(800,000×2,100) = √1,680,000,000 ≈ 40,987.8 USDC（估法：41,000²=1.681万亿，略小）
3. 验算：19.518×40,987.8=800,000 ✓；40,987.8/19.518=2,100 ✓
4. 答案 = 新储备 − 原储备：换回 20−19.518 = **0.482 ETH**；投入 40,987.8−40,000 = **$987.8**；均价 $2,049.4（推价税 ≈ +2.47%）。
